For this assignment in Module 5, I modified an existing project for CountryInfoService to use the Football Pool public SOAP webservice from list of services provides

I added an input validation to check that the players name was text and met a specific length in character requirements. Flask was also integrated so that users could submit requests through GET and POST methods instead of having the information entered directly into the terminal. This program will show players ID, first name, last name, as well as full name.

During the creation and adding changed i was surprised at how Zeep uses WSDL to make a SOAP operation without the input of manually constructing SOAP messages. 

This assignment helped me understand flask a little more on how Flask receives user input and returns JSON responses. This assignment helped with the understanding of SOAP, WDSLs, input validation, exception handling and web services. I would like to get more familiar with these tasks better in the upcoming assignments and testing/making some of my own as practice in the future.
